# Telegram Section Router Bot (v2.2)

Web Dashboard এবং Telegram Webhook বট — বড় মেসেজকে বিভক্ত করে ক্রমানুসারে নির্দিষ্ট টেলিগ্রাম গ্রুপ/টপিকে পোস্ট করার স্বয়ংক্রিয় সিস্টেম।

---

## 🚀 ডিসপ্যাচ সিকোয়েন্স (Dispatch Sequence)

১. **ছবি (Photos First):**
   - সবার প্রথমে একক বা একাধিক ছবি (বা ছবির লিঙ্ক) টেলিগ্রাম টপিকে পাঠানো হয়।
   - একাধিক ছবি থাকলে স্বয়ংক্রিয়ভাবে Telegram Media Group (অ্যালবাম) আকারে সেন্ড হয়।

২. **আপারকেস হেডার মেসেজ (UPPERCASE Header with SKU & Prices):**
   - **Headline / Title**: সম্পূর্ণ UPPERCASE
   - **Product Name**: <code>PRODUCT NAME</code>
   - **SKU / Code**: <code>SKU CODE</code> (১-ক্লিক কপি)
   - **Costing**: <code>COSTING</code> (e.g. 1200 BDT)
   - **Sale Price**: <code>SALE PRICE</code> (e.g. 1850 BDT)
   - **Sources**: `<a href="...">Source</a>` (শুধুমাত্র **Source** লেখাটি দৃশ্যমান থাকবে এবং ক্লিক করলে লিঙ্ক ওপেন হবে)
   - **Link**: `<a href="...">Link</a>` (শুধুমাত্র **Link** লেখাটি দৃশ্যমান থাকবে এবং ক্লিক করলে লিঙ্ক ওপেন হবে)

৩. **আলাদা সেকশন মেসেজ (Clean Individual Sections):**
   - এরপর বডির প্রতিটি সেকশন একটি একটি করে আলাদা মেসেজে পাঠানো হয়।
   - প্রতিটি সেকশনের মেসেজের ভেতরে কোনো অপ্রয়োজনীয় হেডার বা প্রোডাক্ট কোড থাকবে না।
   - পুরো সেকশন ১-ক্লিকে কপি করার জন্য `<pre>` কোডব্লক ফরম্যাটে থাকে।

---

## 🛠️ ফিচারসমূহ (Features)

1. **৪টি নতুন ইনপুট ফিল্ড (Costing, Sale Price, Sources, Link):**
   - SKU-এর পর কস্টিং, সেল প্রাইস, সোর্স লিঙ্ক এবং প্রোডাক্ট লিঙ্ক দেওয়ার ইনপুট।
   - সোর্স এবং লিঙ্কের বড় ইউআরএল লুকিয়ে শুধু ক্লিকেবল **Source** ও **Link** টেক্সট দেখানো হয়।
2. **মাল্টি-ইমেজ সাপোর্ট ও লাইভ থাম্বনেইল প্রিভিউ:**
   - ওয়েব ড্যাশবোর্ডে ছবির লিঙ্ক দেওয়ার সাথে সাথে নিচে থাম্বনেইল গ্যালারি দেখা যায়।
3. **লাইভ ডিসপ্যাচ প্রিভিউ ও ১-ক্লিক কপি:**
   - ড্যাশবোর্ডের ডানপাশে টেলিগ্রামে মেসেজ কেমন দেখাবে তা লাইভ প্রিভিউতে দৃশ্যমান এবং প্রিভিউতেই Source ও Link টেস্ট করে ক্লিক করা যায়।
4. **হেডার পিন অপশন (Pin Header Message):**
   - টেলিগ্রাম টপিকে মূল হেডার মেসেজটি স্বয়ংক্রিয়ভাবে পিন করে রাখার অপশন।
5. **সাইলেন্ট ডিসপ্যাচ (Silent Dispatch):**
   - নোটিফিকেশন সাউন্ড ছাড়া নিঃশব্দে মেসেজ পাঠানোর টগল।
6. **অটো-চাঙ্কিং (Safe 3900+ Char Splitter):**
   - কোনো সেকশন ৩৯০০ অক্ষরের বেশি হলে টেলিগ্রাম লিমিট না ভেঙে ছোট অংশে ভাগ করে পাঠানো হয়।
7. **লোকালস্টোরেজ ড্রাফট সেভ:**
   - ব্রাউজার রিফ্রেশ করলেও ড্রাফট সেভ থাকবে।
